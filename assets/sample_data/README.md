# Sample Data

Files in this folder are generated by the original monolithic Chapter 2 notebook
(kept as a reference copy). Running it top-to-bottom recreates all of them.

| File | Created by (section) | Purpose |
|------|-----------------------|---------|
| `employee_policy.pdf` | Section 4 | 3-page PDF with deliberate repeated header/footer noise |
| `leave_policy.docx` | Section 5 | Word file with Heading 1 / Heading 2 structure |
| `customers.csv` | Section 6 | Small table for row-serialization |
| `policy.txt` | Section 15 | Messy text (extra spaces + decomposed Unicode) for the full pipeline |

The modular Chapter 2 notebooks (2a onward) use `assets/real_corpus/` instead — see
[`utils/corpus.py`](../../utils/corpus.py).

Safe to delete this folder at any time; re-run the notebook to regenerate it.
